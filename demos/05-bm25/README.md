# 05-bm25

ES 默认相关度就是 **BM25**。本课只做一件事：改 `k1` / `b`，看同一查询下短文/长文分数怎么变。

## 参数直觉

| 参数 | 常见默认 | 调大时大致效果 |
|------|----------|----------------|
| `k1` | 1.2 | 同一词重复出现，加分更「敢」 |
| `b` | 0.75 | 长文档更吃亏；`b=0` 几乎不按长度惩罚 |

## 运行

```bash
# 需已装 IK（与 04 相同镜像）
python demos/05-bm25/main.py
# Dev Tools：console.http（含 _explain）
```

## 预期

- 两组索引文档相同，但 `_score` / 排序可能不同
- `b=0` 时，长文里多次出现「机械键盘」更容易保住高分
- `_explain` 能看到分数拆解（不必抠公式细节）
